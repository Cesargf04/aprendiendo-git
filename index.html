Introducción

Este proyecto documenta mi aprendizaje sobre Git, GitHub y el control de versiones.

¿Qué es Git?

Git es un sistema de control de versiones distribuido que permite registrar cambios en los archivos de un proyecto y consultar su historial.

Principales ventajas de Git

  • Permite mantener un historial de cambios.
  • Facilita el trabajo mediante ramas.
  • Ayuda a colaborar con otros desarrolladores.
  • Permite fusionar diferentes versiones del proyecto.
  • Facilita la recuperación de versiones anteriores.

3.1 Ramas locales y remotas en Git

Las ramas permiten desarrollar nuevas funcionalidades sin modificar directamente la rama principal del proyecto.

Tipos de ramas

  • Rama main: contiene la versión principal del proyecto.
  • Ramas feature: permiten desarrollar nuevas funcionalidades.
  • Ramas remotas: representan ramas almacenadas en GitHub.

Comandos utilizados

  • git branch: muestra las ramas locales.
  • git switch -c: crea una rama y cambia a ella.
  • git switch: permite cambiar de rama.
  • git merge: integra los cambios de una rama.
  • git branch -d: elimina una rama fusionada.

4.2 Colaboración con Git y GitHub

En esta práctica aprendimos a trabajar de manera colaborativa utilizando Git y GitHub.

Trabajo en equipo

Colaboré con César en su repositorio, creando una rama independiente para proponer mejoras sin modificar directamente la rama principal.

Herramientas utilizadas

  • Git Clone: descargar el repositorio.
  • Git Branch: trabajar en ramas independientes.
  • Git Commit: registrar los cambios realizados.
  • Git Push: enviar los cambios a GitHub.
  • Pull Request: proponer cambios para revisión.

Aprendizaje obtenido

Comprendí la importancia de la comunicación, la organización de ramas y la revisión de cambios durante el desarrollo colaborativo.
